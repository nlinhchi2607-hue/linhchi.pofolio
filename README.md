## ✨ Điểm Nổi Bật Của Website

- 🎨 **Giao diện Trò chơi Nhập vai (RPG / Kawaii Arcade)**: Tông màu chủ đạo **Hồng & Trắng (Sakura Pink & Cloud White)** kết hợp hiệu ứng huy hiệu lơ lửng, quầng sáng Holographic và các thẻ bài phong cách Anime / Otome game.
- 🎮 **Top Game HUD Status Bar**: Hiển thị thanh máu **HP** (Năng lượng 100/100), mana **MP** (Học thuật 100/100) và điểm kinh nghiệm **EXP**.
- 💬 **Hộp thoại Tương tác NPC**: Nhấp vào ảnh chân dung hoặc khung thoại của Gia sư Linh Chi để lắng nghe lời thoại cổ vũ và mẹo học tập được cập nhật liên tục.
- 🔊 **Âm thanh Game 8-Bit Retro**: Tích hợp bộ tổng hợp âm thanh bằng **Web Audio API** (không cần tải file ngoài), hỗ trợ âm click, âm nhặt xu (`coin`), âm thăng cấp (`level up`) với nút Bật/Tắt tiện lợi.
- ⚔️ **Mini-Game Arcade (English EXP Battle)**: Thử thách trắc nghiệm tiếng Anh 3 vòng giúp người xem vừa chơi vừa nhận điểm EXP và mở khóa phần quà kiểm tra trình độ miễn phí.
- 📖 **Sách Phép Thuật Từ Vựng (IELTS Word of the Day)**: Tích hợp công nghệ **Web Speech API** phát âm chuẩn giọng bản xứ (US/UK) chỉ với 1 click.
- 🌸 **Canvas Cánh Hoa Bay**: Hiệu ứng cánh hoa rơi nhẹ nhàng trong không gian có thể bật/tắt linh hoạt.
- 📱 **100% Responsive**: Tương thích mượt mà trên cả Điện thoại di động, Tablet và Màn hình máy tính.

## 🚀 Hướng Dẫn Kích Hoạt GitHub Pages (Đưa Web Lên Mạng Miễn Phí)

1. Đưa toàn bộ mã nguồn lên repository GitHub của bạn.
2. Truy cập vào repository trên GitHub ➡️ Chọn **Settings** (Cài đặt).
3. Ở menu bên trái, chọn mục **Pages**.
4. Tại phần **Build and deployment** ➡️ mục **Branch**, chọn nhánh `main` (hoặc `master`) và thư mục `/(root)`.
5. Nhấn **Save**. Sau khoảng 1 phút, GitHub Pages sẽ cấp cho bạn một đường link website online công khai miễn phí (ví dụ: `https://your-username.github.io/portfolio/`) để bạn chia sẻ cho học sinh và phụ huynh!
